# Metas (`goals`)

Las metas de ahorro: cuánto se quiere juntar y para cuándo, sus aportes y retiros, y cuánto va y cuánto falta.

- **Feature flag:** `FEATURE_GOALS`
- **Capas:** `domain`, `application`, `ports`, `infrastructure`, `http` (ver [ADR-0001](../../../../docs/adr/0001-monolito-modular.md))
- **Ficha completa:** [`docs/modules/goals.md`](../../../../docs/modules/goals.md)
