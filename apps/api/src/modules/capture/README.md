# Bandeja (`capture`)

La captura móvil: lo que mandan el atajo de iPhone o la automatización de Android con un token personal, la bandeja donde se revisa (corregir, confirmar, descartar) y las reglas que sugieren la categoría.

- **Feature flag:** `FEATURE_CAPTURE`
- **Capas:** `domain`, `application`, `ports`, `infrastructure`, `http` (ver [ADR-0001](../../../../docs/adr/0001-monolito-modular.md))
- **Ficha completa:** [`docs/modules/capture.md`](../../../../docs/modules/capture.md)
